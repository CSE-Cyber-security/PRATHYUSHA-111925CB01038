# Java Factorial Calculator

A simple Java program that calculates the factorial of a number entered by the user.

## About the Project

This program is created using Java and demonstrates the use of:

- User input
- `Scanner`
- `for` loop
- Variables
- Arithmetic operations

## Example

If the user enters:

5

The program calculates:

5 × 4 × 3 × 2 × 1 = 120

Output:

```text
Enter a number: 5
Factorial of 5 = 120
